# cleandiary

청소업체 스케줄 관리 웹앱. 휴대폰에서 앱처럼 쓰는 용도.

## 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (HTML/CSS/JS 한 파일) |
| `sw.js` | 오프라인에서도 열리게 해주는 파일 |
| `vercel.json` | 배포 설정 (수정 내용이 바로 반영되게 함) |

빌드 과정 없음. 이 폴더를 그대로 GitHub에 올리고 Vercel에 연결하면 끝.

## 기능

- **3주 달력** — 좌우로 밀거나 화살표로 주 이동, `오늘` 버튼으로 복귀
- **정기청소 탭** — 매주 / 격주 / 매월 n일 / 매월 n번째 요일 반복 등록, 한 번 등록하면 자동으로 계속 채워짐
- **새벽 구분** — 등록할 때 고른 요일이 **실제로 청소하는 새벽 요일**. 그 날짜 칸의 **맨 위**에 점선 + 진한 색으로 놓이고, `◂월밤`처럼 **전날 밤에 출발**한다는 표시가 붙음. 칸 안 순서는 새벽 → 아침 → 오후 → 저녁
- **상세 배너** — 현장을 누르면 위에서 펼쳐짐 (주소·담당자·출입·주차·작업내용·특이사항·금액·계산서)
- **일회성 탭** — 자유 입력, 첫 줄이 달력 칸에 표시되고 정기 달력에도 초록 점선으로 함께 보임
- **메모 탭** — 날짜별 메모, 메모 있는 날 점 표시, 그날 방문 현장 자동 표시, 검색, 자동 저장
- **백업/복원** — 설정에서 JSON 파일로 내보내기·불러오기

## 데이터

모든 데이터는 사용하는 기기의 브라우저 저장소(localStorage)에 저장됩니다.
서버·로그인·비용 없음. 대신 기기를 바꾸거나 브라우저 데이터를 지우면 사라지므로
가끔 **설정 → 백업 파일 내보내기**로 파일을 보관해 두세요.
